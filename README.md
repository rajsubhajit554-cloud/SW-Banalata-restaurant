## How to Update Git Repository

To push future updates to GitHub easily:
1. Double-click the `update_git.bat` file in this folder (or run `.\update_git.bat` in Terminal/PowerShell).
2. Enter your commit message when prompted (or press Enter for default message).
3. The script will automatically stage all changes, commit, and push them to GitHub!
